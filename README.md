# BudgetFlow

Experiencia interactiva paso a paso de presupuesto personal: minimalista, céntrica, con animaciones suaves entre escenas, apartado detallado para servicios (luz, agua, gas, internet, vivienda), gráficos visuales fáciles de entender y generación de documento imprimible en PDF.

## Flujo guiado en 6 pasos

1. **Ingreso:** Define tu ingreso neto, frecuencia y moneda con cálculo anual instantáneo.
2. **Estrategia:** Elige entre **50/30/20**, **60/20/20**, **70/20/10**, **45/25/30** o **Personalizado** mientras ves el porqué de cada método.
3. **Tus gastos:** Detalla cuánto gastas en vivienda, luz/electricidad, agua, gas, internet, supermercado, transporte, gustos y ahorro con termómetro visual y gráfico de tus mayores gastos.
4. **Gráficos:** Explora el **Gráfico Circular Grande** o cambia a **Barras fáciles ("Lo ideal vs Lo tuyo")** y ajusta cualquier bloque en vivo.
5. **Diagnóstico:** Obtén tu índice de salud financiera (`0–100`), análisis de servicios del hogar, proyecciones y simulador de mejoras en 1 clic.
6. **Documento imprimible:** Revisa el informe ejecutivo completo y guárdalo en PDF o imprímelo (`@media print`).

## Ejecución local

Proyecto 100% estático (HTML, CSS y JS sin compilación previa).

```bash
python3 -m http.server 8080
```
